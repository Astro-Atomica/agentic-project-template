# Personas

Optional specialist agent roles can live here.

Only add a persona when a recurring task benefits from a stable role, scope, and handoff pattern.

Invoke an agent persona when it is necessary for the task or when the user asks for work from that perspective. A user may phrase this in many ways, such as "as `{persona}` do `{task}`"; treat that as a general form, not a rigid invocation template.

Use [model routing](../rules/model-routing.md) to associate a persona with a preferred model, effort setting, and tools. Keep the persona's responsibilities separate from that configuration so users can change models without rewriting the role.
