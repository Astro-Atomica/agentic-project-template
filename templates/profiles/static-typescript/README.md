# Static TypeScript Profile

For static web apps, dashboards, and client-side tools.

Consider adding:

- `workspace/src/`
- `workspace/public/`
- `workspace/package.json`
- `workspace/tsconfig.json`
- `workspace/vite.config.ts`

Common ignored outputs:

- `workspace/node_modules/`
- `workspace/dist/`
- `.vite/`
