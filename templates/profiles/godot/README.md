# Godot Profile

For Godot games and interactive tools.

Consider adding:

- `workspace/project.godot`
- `workspace/scenes/`
- `workspace/scripts/`
- `workspace/assets/`
- `workspace/addons/`
- `workspace/exports/`

Common ignored outputs:

- `workspace/.godot/`
- `_build/`

Commit Godot import metadata intentionally according to the Godot version and asset pipeline in use.
