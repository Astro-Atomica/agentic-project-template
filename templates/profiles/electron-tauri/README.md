# Electron / Tauri Profile

For desktop applications.

Consider adding:

- `workspace/src/`
- `workspace/public/`
- `workspace/src-tauri/` for Tauri
- `workspace/electron/` for Electron main/preload code

Common ignored outputs:

- `workspace/node_modules/`
- `workspace/dist/`
- `workspace/src-tauri/target/`
- `_build/releases/`
