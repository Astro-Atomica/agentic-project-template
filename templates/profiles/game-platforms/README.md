# Game Platform Profile

For projects targeting Steam, Xbox, Switch, or other distribution platforms.

Consider adding:

- `workspace/game/`
- `workspace/assets/`
- `workspace/tools/`
- `docs/platforms/`
- `docs/certification/`

Common ignored outputs:

- `_build/`
- platform SDK generated output
- local devkit configuration

Never commit platform SDK secrets, credentials, private documentation, or NDA-restricted files.
