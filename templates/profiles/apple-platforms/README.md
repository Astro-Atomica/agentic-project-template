# Apple Platforms Profile

For iOS, macOS, iPadOS, and visionOS apps.

Consider adding:

- `workspace/AppName.xcodeproj/`
- `workspace/AppName/`
- `workspace/AppNameTests/`
- `workspace/AppNameUITests/`

Common ignored outputs:

- `DerivedData/`
- `*.xcuserstate`
- `xcuserdata/`

Commit shared schemes and project configuration intentionally. Keep user-specific Xcode state ignored.
